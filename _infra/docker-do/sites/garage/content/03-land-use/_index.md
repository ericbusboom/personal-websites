## LAND-005: Setbacks, Retained Garage, and Proposed Storage Roof

**Revision 0 · 2026-09-15 · Status: Draft**

### Key findings

- **Retained garage (existing)**: The existing garage has a 3-foot side-yard setback under the current San Diego Municipal Code. This is the minimum for accessory structures on this lot.
- **Proposed storage roof addition**: New construction above the existing garage is subject to current code. The minimum side-yard setback for the proposed addition is **5 feet**.
- **Side strip roof (15-ft)**: The San Diego Development Services Department described a 15-foot side-strip roof as a **conditional option requiring City interpretation**. It is NOT an approved limit for this project. If pursued, this would require a formal DSD determination.

### Permit path

The current understanding (per informal DSD guidance): structural work supporting PV and construction of a new accessory structure requires **building review in addition to electrical requirements**. A separate electrical permit is also required. The exact permit path depends on survey results and formal classification of the upper level.
