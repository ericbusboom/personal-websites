## Writing Questions

See our guide for [How to Write a Good Data Question](</2018/11/how-to-write-a-good-data-question/>). The question editor uses [Markdown](<https://www.markdownguide.org/basic-syntax>) for formatting. The most important formatting is available from the buttons at the top of the editor, but you can also use more advanced Markdown syntax. **Images**. The image button in the editor requires entering a link. If you want to upload an image and link it into you question or answer, you must: 

  1. Upload the image file by clicking on the 'Choose File' button at the bottom.
  2. Submit the question to upload the file and get an attachment link.
  3. Copy the link ( right click in your browser )
  4. Edit the answer, click on the Insert Image button and paste in the image URL.
