This collection of police data supports our Police Data Analysis project. 

## San Diego Crime Incidents

The most useful packages for analysis are [San Diego Crime Incidents with Demographic Descriptions](<http://data.sandiegodata.org/dataset/sandiegodata-org-crime-victims/>), while holds recent crime incident data that links victims and offenders, and [San Diego Region Crime Incidents 2007 – 2013](<http://data.sandiegodata.org/dataset/sandag-gov-crime-2007e2013/>), which, although older, has many detailed features that are useful for analysis.
