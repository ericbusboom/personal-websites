I'm in training this afternoon for using the API for [San Diego's CityIQ Smart street lamps](<https://www.ge.com/reports/light-bright-san-diego-leads-way-future-smart-cities/>). These street lamps have cameras and computers that can detect and report: 

  * Parking, cars moving into and out of a parking space
  * Count and speed of cars in street
  * Pedestrian counts, speed and direction
  * Environmental measurements: temperature, humidity

I'll be working on extracting some of this data into an analysis package, so[ let me know](<http://www.sandiegodata.org/about/contact/>) if you'd like to work on a data project using the data.
