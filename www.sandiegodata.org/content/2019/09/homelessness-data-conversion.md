The San Diego Data Library is building a detailed data set about Downtown homelessness using 5 years of hand-marked paper maps. The conversion process is human-powered, and we need you help to finish the conversion. When we are finished, we will have a very valuable data for doing detailed analysis of the relationship between unsheltered homeless people and the downtown environment, exploring factors such as restrooms, vacant lots, and the presence of services. 

Join other civic-minded volunteers to help convert the final few files and get started on the data analysis at our next meeting: [Wednesday, October 9, at WeWork, 600B](<https://www.meetup.com/Data-Science-for-Non-Profits/events/mzcnfryznbmb/>)

At the meeting, you will be using a web based tool to work through the [remaining tasks](<https://github.com/sandiegodata-projects/downtown-partnership/issues?utf8=%E2%9C%93&q=is%3Aissue+is%3Aopen+-label%3ABug+>). These tasks involve using a web based tool to draw circles around hand written marks on scanned paper maps. Here is an example of one of the maps with the circle annotations. 

![](/uploads/7/2019/09/Screen-Shot-2019-09-03-at-4.55.15-PM-1024x790.png)

These marks will be added to the final dataset, resulting in a detailed dataset of homeless person positions in Downtown San Diego. Here is a map of the data points we have so far. 

![](/uploads/7/2019/08/Downtown-Homelessness-1024x652.png)

When we're finished, we will start doing the analysis to answer questions that [researchers and policy experts have asked that we can answer with this dataset](</tags/homelessness/>), primarily questions related to how homeless people cluster depending on changes landuse, restrooms, and other services. 

If you'd like to help,[ join the Meetup event](<https://www.meetup.com/Data-Science-for-Non-Profits/events/mzcnfryznbmb/>), and we'll see you in October.
