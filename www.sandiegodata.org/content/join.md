Here are a few things you’ll need to do to join one of the Data Library’s projects

  * [Join our meetup group](<https://www.meetup.com/San-Diego-Regional-Data-Library/>). Meetup.com is the primary location for posting project meetings and collecting RSVPs.
  * [Create a Github account](<https://github.com>). You’ll need a Github account username for your Redmine account.
  * Join the management site: 
    * Some projects are managed on Redmine, so you'll need to [register an account on Redmine](<https://redmine.civicknowledge.com/account/register>)
    * Simpler, less formal projects have a website with a link to a Google forum for the group.
  * Install a Python data science environments, which must include Jupyter. For most people, the second easiest way to do this is to install Anaconda. The easiest is to use [Google Colaborator](<https://colab.research.google.com/notebooks/intro.ipynb#recent=true>)
  * Send an email about which project you are interested in to the project manager, [Eric Busboom](<mailto:eric@sandiegodata.org>)


Attending regular project meetings is valuable, not strictly required; there are plenty of activities that you can find and complete from Redmine tickets.
