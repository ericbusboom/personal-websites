_Temporally calibrated DMSP-OLS NTL time series data from 1992-2013; and converted NTL time series from the VIIRS data (2014-2018) Spatial resolution: 30 arc-seconds (~1km)_

`figshare.com-harmonized_ntl-1.1.1`. Modified 2021-07-12T20:47:57

Resources | Packages | Documentation| Contacts| References

## Documentation

This dataset provides reference links to each of the annual noghtime lights images from a collection of images built from DMSP and VIIRS data, for the years 1992 to 2018.
