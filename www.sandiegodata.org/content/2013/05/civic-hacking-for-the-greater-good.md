[Use your hacking skills for a better San Diego!](<http://codeforsandiego.org/sddoci/>) Open San Diego, San Diego Code For America Brigade, Cali IT2,  and OpenGeo are sponsoring a Civic Day of Hacking. The San Diego Regional Data Library will be presenting many of our datasets and running a crime analysis project, so join us if you'd like to learn how to use Python and QGIS to work with crime, census and infrastructure data. See the [Code for San Diego](<http://codeforsandiego.org/sddoci/>) website for more information.
