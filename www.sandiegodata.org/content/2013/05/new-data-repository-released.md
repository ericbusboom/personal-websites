Today we are releasing an update to our data repository, at [/dataset/](</dataset/>). This release is based on CKAN 2.1, the same software used to run [Data.Gov](<http://data.gov>), one of the largest data sites in the world. The software is more capable than the older version, and it is much more attractive, with better visual design and organization.
