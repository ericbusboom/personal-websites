We're looking for some programers to visualize crime data and present it at our booth at the [San Diego Magazine Big Ideas Party on Jan 21](<http://www.sandiegomagazine.com/San-Diego-Magazine/November-2014/The-Big-Ideas-Party/>). The Data Library was [one of the 25 Big Ideas](<http://www.sandiegomagazine.com/San-Diego-Magazine/January-2015/25-BIG-Ideas/>) covered in their January issue, so they'd like us to have a presentation at the party. I'd like to have an interactive display, probably using [D3](<http://d3js.org/>), that shows a crime hot spot map for the region, as well as a collection of [time-based Rhythm maps](<http://www.sandiegodata.org/2014/04/burglary-rhythm-maps/>) for selected areas. A visitor to the booth could select a neighborhood or city, see the hot spots in that area, and see how the crime incidents change in that area over time. So, we'll need a Python programmer for the server side ( Pandas for analysis, Flask or similar for the server ) and Javascript person for the front end. Someone with solid visual design skills would be a plus. You'll get a ticket to the [party on the 21st](<http://www.sandiegomagazine.com/San-Diego-Magazine/November-2014/The-Big-Ideas-Party/>), to share in the glory, get free food, and do some high-quality hobnobbing. If you are interested, send me an email, with a link to your Github/Bitbucket/etc account or portfolio, to [eric@sandiegodata.org](<mailto:eric@sandiegodata.org>). We can use any number of volunteers, but I only have three free tickets.
