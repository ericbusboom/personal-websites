We're working on [building a new knowledge base](<http://kb.sandiegodata.org/>), a collection of example Jupyter notebooks related to projects the Library has been working on. The notebooks include detailed analyses using Jupyter, Python, Pandas and other tools, with most of the notebooks covering crime and demographics. For instance, the [Demographics and Business Loans](<http://kb.sandiegodata.org/notebooks/demographics-and-business-loans/>) notebooks shows how to fetch American Community Survey data and create a radius around the highest minority area in San Diego, displaying it a Leaflet Map: [![](/uploads/12/2017/11/Screen-Shot-2017-11-25-at-4.44.07-PM.png)](</uploads/12/2017/11/Screen-Shot-2017-11-25-at-4.44.07-PM.png>) Or, from the [San Diego Police Calls For Service](<http://kb.sandiegodata.org/notebooks/san-diego-police-calls-for-service/>), a rhythm map of reports of loud parties, by neighborhood.   [![](http://kb.sandiegodata.org/img/san-diego-police-calls-for-service/output_30_0.png)](<http://kb.sandiegodata.org/img/san-diego-police-calls-for-service/output_30_0.png>) Loud Party Rhythm Map Each of the notebooks includes a link [to our example notebooks github repository](<https://github.com/sandiegodata/notebooks>), so you can also get the full source and run them yourself.
