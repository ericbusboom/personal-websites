This site is the main data repository for the [San Diego Regional Data Library.](</>) Visit the Data Library's main website for the [Library's news, analysis and projects](</>).

This site uses [Metatab and Metapack ](<https://metatab.org>)to manage all of the data packages. Using Metapack, data packages are described by CSV format metadata, built in to ZIP packages, and deployed to this Wordpress website. Using the same package, data can also be published to S3, CKAN and Data.World, and using the [metapack python module](<https://pypi.org/project/metapack/>), the packages can be opened and used in Python and Jupyter.
